# UP03. Diseño responsive, frameworks CSS y preprocesadores

FestWeb ya dispone de una estructura HTML y de un sistema de estilos coherente, pero una interfaz web no puede diseñarse pensando únicamente en una pantalla de escritorio.

Las personas usuarias pueden acceder desde teléfonos móviles, tabletas, portátiles o monitores de gran tamaño. La interfaz deberá reorganizar sus contenidos, adaptar sus dimensiones y mantener la legibilidad y facilidad de interacción en todos ellos.

> **Pregunta de partida:**  
> ¿Cómo podemos conseguir que una misma interfaz se adapte a diferentes pantallas sin crear una versión independiente para cada dispositivo?

## ¿Qué aprenderemos?

A lo largo de esta unidad aprenderemos a:

- Identificar los problemas que presentan las interfaces rígidas.
- Utilizar unidades relativas, contenedores fluidos y recursos adaptables.
- Crear composiciones flexibles mediante Flexbox y CSS Grid.
- Aplicar una estrategia mobile first.
- Utilizar media queries y puntos de ruptura.
- Comprobar una interfaz en diferentes resoluciones.
- Construir interfaces responsive mediante Bootstrap.
- Personalizar los componentes de un framework.
- Organizar y reutilizar estilos mediante Sass.
- Compilar archivos SCSS para generar hojas CSS interpretables por el navegador.

!!! info "Idea clave"

    El diseño responsive no consiste únicamente en reducir el tamaño de los elementos. También implica reorganizar los contenidos y conservar su jerarquía, legibilidad y facilidad de interacción.
