
En el desarrollo de aplicaciones web es fácil caer en la confusión de pensar que una interfaz es únicamente una capa estética. Desde una perspectiva profesional y metodológica, la interfaz es el canal de unión donde la comunicación de la aplicación y el usuario se interconectan.

Haciendo un símil con los vehículos, el *backend* representaría el motor, mientras que la interfaz sería el salpicadero, el volante y los pedales. Por muy potente que sea un motor, el vehículo sería inútil si no tuviera indicadores o volante para poder utilizarlo.

### 2.1. Interfaz web

Podemos definir una interfaz web como el entorno digital, visual y funcional estructurado mediante tecnologías web —HTML, CSS y JavaScript— que actúa como punto de encuentro e interacción entre un sistema informático y un ser humano. Su propósito principal es actuar como un traductor universal. Los sistemas informáticos operan mediante lógica binaria, flujos de datos estructurados y procesos de servidor.

!!! bloque-descriptivo "Información de interés"
    El ser humano procesa la información a través de estímulos visuales, modelos mentales y acciones físicas. La interfaz traduce la complejidad técnica del sistema en elementos perceptibles y accionables, permitiendo que ambos se entiendan y colaboren.

### 2.2. Página, sitio y aplicación web

Debemos diferenciar estos tres conceptos. Aunque a nivel coloquial se empleen como sinónimos, existen diferencias:

- **Página web (*web page*):** es la unidad mínima de información de la Web. Consiste en un único documento electrónico —normalmente con extensión `.html`, `.php`, etc.— identificado por una URL específica. Puede contener texto, multimedia y enlaces a otras páginas.
- **Sitio web (*website*):** es un espacio virtual compuesto por un conjunto estructurado de páginas web conectadas entre sí que comparten un mismo dominio de Internet. Su propósito principal suele ser estático o informativo. El usuario adopta un rol predominantemente receptor o lector.
- **Aplicación web (*web app*):** es un software interactivo que se ejecuta en el navegador, pero cuya lógica y procesamiento pueden distribuirse entre cliente y servidor. A diferencia del sitio web, gestiona estados complejos, puede requerir la autenticación de usuarios, realiza peticiones asíncronas e interactúa con bases de datos.

### 2.3. La interacción persona-ordenador

La **interacción persona-ordenador (IPO)** es la disciplina que estudia el diseño, la evaluación y la implementación de sistemas informáticos interactivos para el uso humano. En el contexto del diseño de interfaces, la IPO nos enseña que el software debe adaptarse a las capacidades cognitivas, las limitaciones físicas y las expectativas psicológicas de las personas, y no al revés.

Para evaluar su calidad, la IPO se centra en dos pilares fundamentales:

1. **Usabilidad:** medida que determina la facilidad de uso, la eficiencia, el aprendizaje y la satisfacción con la que un usuario puede interactuar con una interfaz para lograr un objetivo concreto.
2. **Accesibilidad:** garantía de que la interfaz pueda ser percibida, comprendida y utilizada por cualquier persona, independientemente de sus capacidades funcionales o de su contexto técnico.

### 2.4. La interfaz como punto de unión

La interfaz web no existe de forma aislada: es un eje donde convergen tres conceptos indispensables para cualquier proyecto de desarrollo:

- **El usuario:** aporta sus necesidades, sus objetivos, su nivel cultural y técnico y sus modelos mentales.
- **La información:** comprende el contenido, los datos, la documentación y la arquitectura en la que se organizan.
- **La funcionalidad:** reúne las herramientas de software, los algoritmos y los procesos que la aplicación es capaz de ejecutar.

Si la interfaz está bien diseñada, el usuario accederá a la información y ejecutará la funcionalidad de manera fluida y transparente, haciendo que la tecnología se vuelva «invisible».

### 2.5. Fundamentos de la comunicación visual

El diseño visual no responde únicamente a criterios subjetivos, sino a principios de comunicación visual orientados a objetivos. El uso estratégico de los elementos visuales busca reducir la carga cognitiva del usuario. Para gestionar una comunicación visual efectiva, debemos dominar:

- **Jerarquía visual:** organizar y disponer los elementos en la pantalla indicando al usuario qué es lo más importante y en qué orden debe leerla. Se logra mediante el control del tamaño, el peso visual y la posición de los componentes.
- **Tipografía:** elegir fuentes que garanticen la legibilidad en pantallas de diferentes densidades y que refuercen el tono y la seriedad de la aplicación.
- **Teoría del color:** utilizar los colores con un código funcional —por ejemplo, rojo para errores y verde para confirmaciones— y como herramienta psicológica para generar confianza, urgencia o calma.
- **Espaciado y espacio en blanco:** emplearlos como elementos de diseño que permiten al usuario descansar de la composición, separar contenidos inconexos y agrupar los elementos relacionados, de acuerdo con las [leyes de la Gestalt](https://psicologiaymente.com/psicologia/teoria-gestalt).

### 2.6. Consecuencias de omitir la planificación visual

Omitir las fases de planificación, prototipado y diseño de una interfaz tiene consecuencias críticas para cualquier proyecto de software, que pueden traducirse en pérdidas económicas, de reputación y de eficiencia.

Una mala interfaz provoca de forma inmediata tres consecuencias negativas:

1. **Confusión y desorientación:** el usuario pierde la sensación de control, no sabe dónde se encuentra dentro de la aplicación, qué acciones puede realizar ni qué ha sucedido tras pulsar un botón.
2. **Tasa de rebote o abandono prematuro:** si el usuario experimenta frustración, lentitud o dificultades para cumplir su objetivo durante los primeros segundos, cerrará la aplicación.
3. **Errores operativos y costes de soporte:** si el usuario introduce datos incorrectos, duplica transacciones o elimina información accidentalmente, se saturan los departamentos de atención al cliente y soporte técnico, incrementando los costes de la empresa.
