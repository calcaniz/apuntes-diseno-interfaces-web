
Para evitar maquetar pantallas a ciegas, sin saber con certeza qué datos deben mostrarse, o estructurar categorías basándose únicamente en el organigrama de la empresa, se utilizan dos técnicas complementarias: el **inventario de contenidos** y el **card sorting**.

### 7.1. Inventario de contenidos

El inventario de contenidos es una auditoría exhaustiva y estructurada de todos los elementos informativos y operativos que formarán parte de la aplicación web. Debemos diferenciar entre:

- **Contenidos:** elementos pasivos orientados al consumo informativo, como textos, imágenes o vídeos.
- **Funcionalidades:** elementos activos o transaccionales que permiten al usuario realizar una acción o modificar datos, como formularios, buscadores o pasarelas de pago.

Para elaborar un inventario realista sin olvidar elementos críticos se recurre a tres fuentes de datos:

- **Análisis de requisitos:** permite extraer de las historias de usuario los datos que necesita el software para operar.
- **Benchmarking:** consiste en estudiar soluciones existentes en el mercado.
- **Matriz de tareas de usuario:** identifica qué información mínima necesita la persona en cada paso para completar sus objetivos sin abandonar el sitio.

### 7.2. Card sorting

El **card sorting** es una técnica participativa de investigación con usuarios utilizada en la arquitectura de la información para descubrir cómo las personas perciben, agrupan y conceptualizan la información.

Consiste en entregar a un grupo representativo de usuarios un conjunto de tarjetas —físicas o digitales— que contienen los diferentes contenidos y funcionalidades extraídos del inventario. A continuación, se pide a los participantes que agrupen las tarjetas según una lógica que les resulte natural e intuitiva.

Existen tres modalidades:

- **Abierto:** el usuario agrupa libremente las tarjetas y crea los nombres de las categorías resultantes.
- **Cerrado:** el usuario clasifica las tarjetas dentro de un conjunto de categorías ya definidas.
- **Híbrido:** se proporciona un conjunto base de categorías fijas, pero se permite al usuario crear nuevas categorías o renombrar las existentes.
